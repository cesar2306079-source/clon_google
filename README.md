# Google Clone

Clon de la página principal de Google hecho con HTML, CSS y JavaScript
puros, sin frameworks.

## Qué hace

Replica el logo, la barra de búsqueda y los botones "Buscar con Google" y
"Me siento con suerte". Al escribir un texto y presionar Enter o dar clic
en un botón, la página redirige a la búsqueda real de Google usando el
texto ingresado como query:

    https://www.google.com/search?q=<texto>

La barra no permite mandar búsquedas vacías.

## Estructura

    index.html   Estructura de la página
    styles.css   Apariencia: barra redondeada, botones, sombras al pasar
                 el cursor
    script.js    Redirección a Google y validación de búsqueda vacía

## Cómo usarlo

No necesita servidor ni instalación. Basta abrir index.html en el
navegador.
